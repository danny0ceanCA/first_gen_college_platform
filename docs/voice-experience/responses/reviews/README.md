# Live measurement reviews

Create `YYYY-MM-DD-live-conversation-review.md` for each reviewed window. Keep raw logs and private conversation evidence outside the repository.

- Before/after comparison and possible confounders:

Candidate transcript classifications and overlap heuristics are not proof of a useful or heard answer. Do not claim production percentiles from a handful of synthetic calls.
