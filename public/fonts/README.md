# Binder handwriting

`patrick-hand.woff` is Patrick Hand Regular by Patrick Wagesreiter, distributed
under the SIL Open Font License in `patrick-hand-OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/patrickhand

Converted from the original `PatrickHand-Regular.ttf` to WOFF with fontTools,
without subsetting, so the supplied language coverage is retained. The font is
served locally; viewing the binder does not require a third-party font request.
